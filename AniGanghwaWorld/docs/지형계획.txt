애니강화월드 지형 계획 (에피소드 추가 기준)
==========================================
그림: docs/지형배치도.png  (빨강 = 이번에 새로 만든 방, 하늘색 테두리 = 앞으로 쓸 빈 공간)

[맵 상태]
  - 256×256칸(최대 크기), 배드랜드 지형. 전체의 약 44%가 검은 빈 바닥(타일 0x29).
  - 보스방은 검은 바닥 위에 떠 있는 "섬" 구조라서, 방 한 칸을 통째로 복사해 붙이면 바로 쓸 수 있다.

[이번에 추가한 방] (tools_dev/add_rooms.py 로 기존 방을 복사)
  L145 그리드아일랜드 (보스방B 복사)  ->  9-1 레이저
  L146 천공투기장     (보스방A 복사)  ->  9-2 히소카 (1인 출전 결투)
  L147 요크신시티     (보스방C 복사)  ->  9-3 클로로 + 환영여단
  L148 예비방         (보스방B 복사)  ->  11-2 오로치
  L149 새 방 나가기 띠 (4개 방 왼쪽 끝)
  - 4개 방 모두 L042(보스방 전체) 안에 있어서 출전 1마리 제한·클리어 후 귀환이 그대로 적용됨.
  - 방마다 P7 시야 유닛(맵 리빌러)과 벽 유닛도 같이 복사함.

[기존 전투장 재사용 계획]
  보스방 A/B/C (L012/L025/L026) : 챕터 1·3·5 보스, 6-3 부우, 7-3 블랙오공, 10-1 마히토, 10-2 조고, 11-1 타츠마키
  마을 (L093)                     : 챕터 4, 6-1 프리저, 7-1 골든프리저 (나가기 L094)
  셀게임장 (L130)                 : 6-2 셀, 7-2 제6우주, 10-R 스쿠나
  힘의대회 무대 (L136)            : 8 힘의대회, FINAL 지렌, 9-R 메르엠, 11-R 보로스·가로우 (양 끝 L138/L140 = 장외)

[앞으로 쓸 빈 공간]
  예비 R1 : x 74~119, y 141~190 (46×50칸)  -> 큰 레이드 전투장 1개 (셀게임장 크기와 비슷)
  예비 R2 : x 83~119, y 213~255 (37×43칸)  -> 중형 전투장 1개 또는 보스방 2개
  예비 띠 : x 62~74,  y 0~135  (13×136칸)  -> 좁아서 대기실·통로·이벤트 발판 용도
  새 방 아래 : L148 아래 x 130~157, y 134~140 은 여유 7칸뿐 (방 추가 불가)

[새 방 추가하는 법]
  1. tools_dev/add_rooms.py 의 ROOMS 목록에 (복사할 원본 로케이션, 붙일 위치 x, y, 새 로케이션 번호, 이름) 추가
     - 붙일 자리가 전부 검은 바닥이 아니면 멈추고 알려줌 (기존 지형을 덮어쓰지 않음)
     - 비어 있는 로케이션 번호: 150 ~ 255
  2. python add_rooms.py 원본.chk 새.chk  ->  base_map.scx 로 다시 묶기
  3. config.py 스테이지의 arena / entry / exit 에 새 로케이션 번호를 넣으면 끝
  ※ 복사가 아닌 새 모양의 지형은 SCMDraft 2 로 base_map.scx 를 열어 직접 그리면 됨.
    (ISOM 정보가 비어 있어서 브러시가 어색하면 "타일에서 ISOM 다시 만들기" 한 번 실행)

  - 챕터 9~11 에서 쓴 칸: 140·141·142(웨이브), 138·204·158·201·161, 143·144·81, 211·147·133·132
  - 아직 남은 재활용 후보: 165 172 170 163 169 164 154 159 167 171 173 155 174 150 152 148 131 135 146 210 25 203 145 153 197
