[빌드하는 법]
  1. euddraft 최신 버전을 받는다 (GitHub의 armoha/euddraft 릴리스).

[스테이지 고치는 법] (config.py 의 CHAPTERS)
  - 보스 바꾸기: phases=[유닛번호, ...]   - 제한시간: time=300
  - 보상: reward=(미네랄, 가스, 강화포인트)  - 문구: intro / lines / clear
  - 보스 스킬: BOSS_SKILLS 의 SK(주기, 연출유닛, 공격유닛, 유지틱 ...)
  - 새 챕터는 CHAPTERS 끝에 dict 하나 추가하면 진행·웨이브·보상이 자동으로 붙음
  - 스테이지 옵션: pre_entry(시작 전에만 입장) / wipe(전멸 패배) / protect(주황 아군 보호)
                   protect_unit(특정 아군 보호) / guard=(보스, 호위)(호위 있으면 무적) / ringout=[장외 로케이션]
                   follow(보스가 방을 옮기면 우리 유닛도 이동) / phase_stats{단계:(체력,쉴드,방어력)}
                   skills={유닛:[SK(...)]} (이 스테이지에서만 쓰는 스킬)
                   hits={유닛:타수} (공격력 상관없이 타수로만 데미지)
  - 새 보스 유닛: 챕터의 units=[(유닛칸, 이름, 체력, 쉴드, 방어력)]
